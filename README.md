# رفاق التحفة — Rifaq al-Tuhfa

تطبيق تعليم التجويد للأطفال (6–12 سنة) على متن **تحفة الأطفال**، يعمل على الهاتف بملف HTML واحد دون خادم.
المشرف يجهّز الرحلة في الاستوديو ← الطالب يتعلم ويسجّل ← المعلم يراجع ويعتمد بتوقيع ECDSA ← يصدر ملف إهداء لطالب جديد.

**الإصدار الحالي: 9.39** (2026-11-01). المنهج: 16 قسمًا، 61 بيتًا، 148 سؤالًا (9 أنواع)، 26 مهمة تسجيل قرآنية.

## التحميل والتشغيل

| المنصة | كيف |
|---|---|
| الويب (أي جهاز، ومنه iPhone/iPad) | https://feras-glitch.github.io/rifaq-al-tuhfa/ — يمكن تثبيته كتطبيق من المتصفح ويعمل دون إنترنت بعد أول فتح |
| أندرويد (هاتف وتابلت) | ملف `Rifaq-al-Tuhfa-*.apk` من [الإصدارات](https://github.com/Feras-glitch/rifaq-al-tuhfa/releases) |
| ويندوز | `Rifaq-al-Tuhfa-Setup-*.exe` (مثبّت) أو `Rifaq-al-Tuhfa-Portable-*.exe` (بلا تثبيت) من الإصدارات |

في كل المنصات توجد صفحة **«فتح ملف وصلك»**: يفتح المعلم ملف الإرسال، ويفتح الطالب ملف الإعادة أو الإهداء، دون البحث عن متصفح. الملف المفتوح لا يُشغَّل كوده؛ تُستخرج بياناته فقط وتعمل بكود التطبيق الموثوق المضمَّن (`web/host.js`).
في أندرويد يظهر التطبيق في قائمة «فتح باستخدام» لملفات HTML، وعند التصدير تُحفظ نسخة في `المستندات/RifaqAlTuhfa` وتُفتح قائمة المشاركة (واتساب، Drive…).

## البناء
- `python3 tools/build_web.py [مجلد]` يبني الموقع (`_site/`) ويتحقق من تجزئات CSP.
- `.github/workflows/build.yml`: دفع وسم `v*` ينشر الموقع على `gh-pages` ويبني APK (Capacitor، `native/android`) وبرنامج ويندوز (Electron، `native/windows`) ويرفقها بإصدار GitHub.
- توقيع APK: أسرار `ANDROID_KEYSTORE_BASE64` و`ANDROID_KEYSTORE_PASSWORD` و`ANDROID_KEY_ALIAS` و`ANDROID_KEY_PASSWORD`. بدونها يُوقَّع بمفتاح تصحيح مؤقت، فتحديث التطبيق يتطلب إزالة النسخة السابقة (وتضيع بياناتها).

## التشغيل السريع
1. **طالب:** افتح `app/تطبيق_الطالب_والمعلم_v9.39.html` على الهاتف أو المتصفح.
2. **مشرف:** افتح `studio/استوديو_المشرف_v9.39.html`، أدخل الأسماء، (اختياريًا) استورد `curriculum/منهج_المرحلة1_كامل_معتمد_v1.3.json`، سجّل، أضف مفاتيح المعلمين، وصدّر.
3. **اختبار:** `pip install playwright && playwright install chromium` ثم ضع الملفات باسم `out_app.html`/`out_studio.html`/`out_mobile.html`/`curriculum.json` في مجلد واحد وعدّل `D` في `tests/test_v939_playwright.py` وشغّله.

## البناء
- التعديلات على الكود تُجرى في `app/` ثم يُعاد حساب تجزئة CSP وتضمين القالب في الاستوديو عبر `tools/build.py` (يتوقع `app.html`, `studio.html`, `mobile.html` في مجلد العمل).
- `tools/patch_app_9.39.py` و`tools/patch_curriculum_9.39.py` توثّق بالضبط ما تغيّر بين 9.38 و9.39.
