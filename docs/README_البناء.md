# البناء والفحص

1. المصدر: `المصدر_sXX_تطبيق_الطالب_والمعلم.html` (آخر إصدار).
2. بناء القالب المضمّن والاستوديو: سكربت build_sXX.py (يحسب تجزئة CSP تلقائيًا).
3. فحص النقر الحقيقي قبل التسليم: `python3 t_realclick.py <ملف التطبيق>` يجب أن يطبع True.
4. فحص CSP: افتح الملف وتأكد من عدم ظهور "Content Security" في وحدة التحكم.
